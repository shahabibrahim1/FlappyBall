# Flappy Ball

Flappy Ball is a simple browser-based game inspired by the classic Flappy Bird. The player controls a ball that must navigate through obstacles by bouncing through gaps. The game features different difficulty modes and customization options.

## 🎮 How to Play
1. Click the "Play" button on the start screen.
2. Use the spacebar or click to make the ball jump.
3. Avoid obstacles and try to achieve the highest score.
4. After a game over, you can restart and try again.

## 🌟 Features
- **Two Difficulty Modes:** Choose between Regular and Hard.
- **Customizable Ball Color:** Select your preferred ball color.
- **High Score Tracking:** Your best score is saved.
- **Dark Mode Support:** Toggle between light and dark themes.
- **Responsive Design:** Works on different screen sizes.

## 📂 Project Structure
The project consists of the following files:

- **flappyBall.html** → Main HTML file containing the game layout and UI elements.
- **flappy.js** → JavaScript file that handles game mechanics, physics, and interactions.
- **style.css** → Main stylesheet for game design, including layout, colors, and animations.
- **intro.css** → Additional styles specifically for the introduction screen and buttons.


## 🛠️ Technologies Used
- **HTML5 Canvas** for game rendering
- **JavaScript** for game logic
- **CSS** for styling
